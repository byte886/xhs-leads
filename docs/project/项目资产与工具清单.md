## 一、代码资产（定位用）

- `backend/src/`：server / config / engine_pool / engine_types / shell_window / browser_client / mirror / collect_pipeline / score / intent / llm_service / risk / license / jsonio / logger / injections / urls / window_layout / watchdog。
- `frontend/src/`：App.vue + api.ts + store.ts + lib/auth.ts + 10 个 .vue 组件（CollectPanel/PublishPage/ClientsPanel/SettingsPanel/StatusBar/WorkArea/CardGrid/CardMenu/FlowBar/ForceLogin）。
- `scripts/packaging/`：launcher.py / xhs_leads.spec / build_mac.sh；`scripts/gen_license.py`：激活码签发；`scripts/accounts.py`：账号 CLI。
- `quality-gates/`：gates.yaml + tools/{python,typescript}.yaml；根 `EQUIVALENT-MUTANTS.md`。
- 测试：`backend/tests`（pytest）、`frontend/src/*.test.ts`（vitest）。
