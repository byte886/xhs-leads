>
> **机器身份**：文杰机=主工作机（`/Users/wenjiechen`，回归目标）；魏强机=`/Users/weiqiang`（承接开发/质检）。
> **定位**：开发环境部署手册；生产交付形态见 §5 与 `docs/project/需求约束清单.md`。

## 0. 系统全景（v3.0 现行形态，无 Docker、无外部 Chrome CDP 手动流程）

```
┌─ CFT 引擎窗口（有头，R-6.16 路线A，CDP 9223 可控）─────────┐
│  窗口一（壳窗/APP，左半屏 960×800，--app 应用模式）         │
│      http://127.0.0.1:8791/  ← Vue3 前端（FastAPI 同源托管）│
│  窗口二（采集调试窗，右半屏，设置开关 collect_tab_visible） │
│      未登录→ /login-hint 提示页；已登录→ xiaohongshu.com/explore │
│  引擎：launch_persistent_context(user_data_dir=data/profile)│
│      内部 stdio 管道控制——无「允许远程调试」弹窗、无钥匙串   │
└──────────────────────────┬─────────────────────────────────┘
                           │ Playwright CDP（同进程）
┌──────────────────────────▼─────────────────────────────────┐
│ server.py（FastAPI，:8791）：采集/评分/克隆/客户库/草稿/   │
│ 发布护栏/登录守卫；同进程 asyncio，与壳单事件循环（R-6.16） │
└────────────────────────────────────────────────────────────┘
```

- **引擎自动拉起**：`backend/src/engine_pool.py` 用 Playwright `launch_persistent_context(channel="chrome" 或内置 CFT, user_data_dir=<数据目录>/profile)` 自动启动；优先内置 Chrome for Testing（独立应用身份，不占日常 Chrome 单实例），CFT 缺失回退系统 Chrome。**用户无需手动开 Chrome、无需点「允许远程调试」、无需配钥匙串**。
- **端口**：前端 8791（占用则自动探测 8800-8899，launcher 把真实端口写入 `XHS_SHELL_URL`）；引擎调试端口 9223（`config.engine_port`，供 e1/t 系列连引擎实例，非外部 Chrome）。
- **登录态目录**：开发态 `data/profile`；打包态 `~/Library/Application Support/xhs-leads/data/profile`（launcher 首启自动从旧 `codex-zhuke/data` 迁移，排除 Chrome 锁文件并容错）。
- **前端形态**：4-Tab（采集/创作/客户/设置）Vue3 应用，构建产物 `frontend/dist/` 由 FastAPI 同源托管。

## 4.5 打包与分发（build_mac.sh）

**打包前置（缺一不可）**：
- 内置引擎 CFT 已存在于 `~/Library/Application Support/xhs-leads/engine/chrome-mac-x64/`（首次开发跑过后由 engine_pool 自动下载；全新机器需先跑一次 dev 让 CFT 落盘，否则 step 2 rsync 源不存在）。
- 品牌图标 `build_resources/icon/XHSLeadsIcon-1024.png` 存在（仓库已含）。
- `extension/lib/extract.js` 存在（DOM 提取运行时依赖，PyInstaller datas 会打进 .app）。
- 当前仅 **Intel/x86_64 构建**（`chrome-mac-x64`）；Apple Silicon Mac 走 Rosetta 2 运行，无原生 ARM 构建。

```bash
bash scripts/packaging/build_mac.sh                 # 默认先 build 前端
bash scripts/packaging/build_mac.sh --no-frontend-build   # 复用现有 frontend/dist，仅重打壳
```

脚本实际步骤（以 `scripts/packaging/build_mac.sh` 为准）：
1. 前端 `npm run build` → `frontend/dist/`（除非 `--no-frontend-build`）。
2. 同步内置引擎 CFT：`~/Library/Application Support/xhs-leads/engine/chrome-mac-x64/` → `build_resources/engine/`（随包分发，客户机无需另装 Chrome；CFT 独立 bundle ID，不占日常 Chrome）。
3. 品牌图标：由 `build_resources/icon/XHSLeadsIcon-1024.png` 生成 `.icns`，同时用于 .app 与内置 CFT 的 Dock/窗口图标。
4. PyInstaller 按 `scripts/packaging/xhs_leads.spec` 打出 `dist/XHSLeads.app`（datas 含 `frontend/dist` + `extension/lib/extract.js` + playwright driver）。
5. post-copy：把 CFT 直拷进 `dist/XHSLeads.app/Contents/Resources/engine/`，并替换其 app 图标（绕过 PyInstaller datas 对签名 bundle 二进制的限制）。
6. **压分发 zip 到桌面**：`~/Desktop/XHSLeads-mac-Intel.zip`（Intel x86_64，`zip -ry` 含资源；每次先删旧 zip 再压）。

> 交付物即该 zip；客户机器双击运行即可，无需 Python/Node/Chrome 前置。

## 5. 登录闭环（现行形态，R-6.26~6.30）

启动后稳定两窗（`collect_tab_visible=true`，运行时 `data/config.json`）：

1. **未登录启动**：壳窗（左半）= `http://127.0.0.1:8791/` 前端，APP 内弹 **ForceLogin 强制登录框**；Tab2（右半）= 本地提示页 `/login-hint`。
2. 点「去登录」→ 壳窗导航真实登录页 `https://www.xiaohongshu.com/login?redirectPath=…`（强制登录无叉；主动重登可关）。
3. 用户扫码/手机号+验证码完成登录。
4. 守卫捕获 `id_token` → `POST /api/auth/import_cookies` 注入引擎 `data/profile` → 登录态落盘。
5. 壳窗自动回 `http://127.0.0.1:8791/`，ForceLogin 关闭；**Tab2 自动从 /login-hint 切到 `xiaohongshu.com/explore`**。重启后登录态保留。

- **关窗语义（R-6.22p）**：关壳主窗 = 整体退出应用（停 uvicorn + 清理引擎）；关采集调试窗（Tab2）= 仅关闭该窗，不退出、不自动复活（重开靠设置开关或重启）。
- **窗口布局**：壳窗/采集窗均 `min(1280, 主屏宽//2) × 800`（1920 主屏 = 960×800），等宽并排不重叠；非无头时 viewport 跟随窗口宽（R-6.27，避免 960 窗显示 1280 布局被裁）。
- 自动化冒烟跳过登录守卫：`CZ_SKIP_LOGIN_GUARD=1`；无窗口事件循环：`CZ_NO_BROWSER=1`。

## 8. 纪律红线

1. **发布永远手动**：`/api/publish` 只由用户在前端手动触发，自动化不得代发。
2. **Cookie/登录态敏感**：`data/`（含 `profile/`、`cookies*.json`、`*.db`）全部不入库（.gitignore 已挡）。
3. **拟人节奏**：请求间隔 `request_interval=[1.0, 1.8]`s 随机抖动，勿改快；触发平台验证立即停止、不连环重试。
4. **改文档/改代码**：新代码一律用新命名（`src`/`xhs-leads`）；历史调研文档保留旧名不改。
