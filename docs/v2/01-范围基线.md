## 十一、口径变更纪律

- 改任何 AC 文字 → 必须同一提交内改对应测试或三态登记，否则 commit 门拦。
- 新增功能 → 先在本文件加 AC 编号（哪怕三态先写 `X`），禁止"先写代码后补需求"。
- 旧编号（R-6.x / P0-x / FR-xx / D-n / F-n）不再新增；历史映射见 `docs/v2/legacy-id-map.md`（P2 阶段生成）。
