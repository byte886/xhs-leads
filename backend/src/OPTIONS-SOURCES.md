# 行业 / 口吻选项的来源与取舍

`options_store.py` 里的默认选项不是拍脑袋定的。这份文件记录每一项为什么在、为什么是这个粒度，
以及哪些地方是综合设计而非某产品原样。

## 一、为什么做成「选项」而不是纯自由文本

这两个字段会被 `profiles_store.profile_prompt_block()` 拼成事实段落，注入
`/api/ai_outline` 的 system prompt。自由填写时同一家店很容易写成「翡翠手镯 / 翡翠 / 翡翠手饰」
三种说法，模型每次理解不同，生成风格就漂。所以给一组稳定候选，同时允许手填、允许改候选本身。

依据：口吻作为提示词字段在业内是常规做法（腾讯混元多 Agent 教程、Loomi、OpenCode 的
`AGENTS.md` 语气字段、RECATOOLS 的 4–5 个样本都单独列了 tone）。

## 二、行业的 12 项：按电商类目粒度拆，不按矿物学拆

小红书珠宝内容天然按「品类」聚类，平台侧类目也是这个粒度，不是按矿物成分分。
若按矿物学拆（如「硬玉」「软玉」），用户看不懂、也不影响提示词里的事实描述。

| 选项 | 依据 |
| --- | --- |
| 翡翠 / 和田玉 / 琥珀蜜蜡 / 其他玉石 | 人人都是产品经理《6000字，带你撕开小红书珠宝流量》给出「翡翠/和田玉/琥珀蜜蜡/其他玉石」互动值 260.83w（新红数据），另有「金银投资」单列 |

| 黄金 | 界面新闻：黄金仍占主导，黄金之外玉石、珍珠、银饰、流行饰品、设计师饰品承接更日常、更个性化的消费需求 |

## 三、口吻的 6 项：说话的人是谁、站什么位置

口吻不是「文体」（不是「文艺/严肃/活泼」），而是「谁在说、凭什么说」。小红书上决定可信度的是这个。

| 选项 | 依据 |
| --- | --- |
| 店主第一人称 | Specflux：成功的小红书文案是 conversational、intimate，用第一人称 "I tried" 而不是 "We recommend"，要像真人不像品牌 |
| 闺蜜安利 | 同上「像朋友分享」的定位；SegmentFault 一文描述的「介于闺蜜安利和真实测评之间的文字风格：有情绪不浮夸、口语化不随意、有信息量不枯燥」 |
| 专业测评 | 人人都是产品经理《小红书上什么内容最好卖》里「测评/避雷型」以第三方公正姿态、树立「懂行、敢说」的信任 |
| 避坑科普 | 同上的「避雷」分支；配 `byerisk` 的违规词改写规则（功效类说法不得医疗化） |
| 源头货主 | 上述「源头溯源玉石」的供给方视角，对应「我是货源，不是转卖」的身份 |
| 收藏玩家 | 非卖家视角（玩家/藏家分享），用于非直接带货的内容 |

加一条业内共通结构作旁证：运营派的人设公式「真实身份 + 一个脆弱点 + 一个坚持」，
以及 AI 种草提示词的通行写法「第一人称 + 一个具体场景 + 1–2 个真实缺点 + 优缺点同框」——
这两条都要求先确定「谁在说」，所以口吻必须在档案里显式给出。

## 四、诚实边界

- 没有哪个产品的字段表与这 12 + 6 一字不差，这是按上述来源收敛出的**综合设计**；
  真实跑通过的证据是：用这些值拼出的提示词能让 `/api/ai_outline` 正确引用档案里的真实价格与地址、
  且不出现「宝子们/家人们」这类 AI 腔。
- 6 个口吻是「起步集」，不是穷举。用户可以加、可以删、可以恢复默认，这正是做成可维护选项的原因。
- 「常发主题」已删除（无消费方：门店视频工具档案 7 字段里没有这一项，RedInk 只有一句话输入；
  按次选题由向导第一步的 5 张结构卡 + 补充方向承担）。
